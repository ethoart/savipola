Browser layout check

Developer check for English, Sinhala and Tamil layouts. It opens the real local app in a frame, waits for fonts, and measures horizontal overflow, clipped controls and touch targets. It uses sample profiles, never submits a form, and never sends a message or changes a registered profile.

This is a geometry check, not proof of translation quality, keyboard behavior on real phones, visual design quality or universal browser compatibility. Run it in each browser you intend to support.
