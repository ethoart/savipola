# Judge demo: target 2 minutes 50 seconds

Record from the deployed Google Cloud URL, after checking real Vertex AI access. Use English narration and clearly label sample prices.

**0:00-0:20 - Human problem.** Introduce the farmer in Dambulla, buyer in Colombo, driver and loader. Explain that selling a harvest means coordinating all four.

**0:20-0:50 - Gen AI leads to action.** Farmer → Harvest AI → paste a short harvest message with explicit quantity, district and asking price → real Vertex draft. Show model and latency, review fields, then publish. Missing details should stay missing. Use a locally checked Sinhala/Tamil input if available; do not claim validated multilingual accuracy.

**0:50-1:10 - Photo information.** My Harvest → Quality check → real photo → Vertex review. Show visible observations and uncertainty. Explain that no safety certification or automatic grade change occurs.

**1:10-1:35 - Sourcing.** Buyer → 600 kg tomato request → proposed supplier split. Then Harvest AI → explain the request's plan. Code calculates stock and prices; Gemini explains the next steps. No order is reserved yet.

**1:35-2:05 - Functioning transaction.** Offer for 40 kg → farmer accepts → show available/reserved ledger. Buyer books a vehicle with an entered distance. Freight costs are separate.

**2:05-2:25 - Local livelihoods.** Book a loader, complete the job, leave a review and fulfil the produce trade. Show sold stock and job history.

**2:25-2:50 - Architecture and evidence.** Show the Cloud Run URL and stack: Vertex AI, Cloud Run, Cloud SQL, Secret Manager. State pilot measures: coordination time, fulfilled kg, landed cost and paid work. Sample transactions are not measured community impact.

If an API fails, show the real error. A previously recorded successful call must be labeled with its recording time; test fixtures must never be presented as a live model response.
