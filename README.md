# SaviPola

SaviPola is a marketplace for Sri Lankan farmers, buyers, transport providers and local workers.

## Team

**Hyper Way**

- Sandun Nayanaka Subasingha

## Project scope

The prototype brings produce listings, buyer offers, inventory updates, private conversations and transport requests into one workflow. Its interface supports Sinhala, Tamil and English. Local workers can list their services.

## Google technology

The existing application source includes Firebase Authentication and optional Gemini calls through Vertex AI. Cloud SQL supports transactional marketplace data. A Firestore feature for private saved harvests is being prepared. Cloud Run is the intended application host.
